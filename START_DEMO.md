# Запуск CRM Demo локально

## Почему `localhost:4173` мог не открываться
`localhost` всегда указывает на **ваш текущий компьютер**. Если сервер поднят в другом окружении (контейнер/удаленный раннер), ссылка `http://localhost:4173` в вашем браузере не увидит этот сервер и даст `ERR_CONNECTION_REFUSED`.

## Быстрый запуск на вашем ПК
```bash
cd /path/to/sambot-proxy
python3 -m http.server 4173
```
После этого откройте:
- http://localhost:4173

## Если нужен доступ с другого устройства
Поднимите туннель (любой сервис, например ngrok/cloudflared) к порту `4173`.
